# Miscrits PT-BR

Tradução de fã do **Miscrits: World of Creatures** para português: interface, habilidades, itens, falas das NPCs, conquistas e descrições. Os nomes dos miscrits ficam em inglês. Só muda o texto que aparece na tela.

Só para o jogo no PC (Windows, Steam).

## Baixar

**[⬇ Baixar a versão mais nova](https://github.com/Juandaf09/miscrits-ptbr/releases/latest)**: lá embaixo, em *Assets*, clique no arquivo `.zip`.

## Instalar

1. Extraia o zip inteiro para uma pasta (botão direito > **Extrair Tudo**).
2. Dois cliques em **Instalar.bat**.
   - Tela azul "O Windows protegeu o computador": **Mais informações** > **Executar assim mesmo**.
3. Feche o jogo se estiver aberto e abra de novo.
4. Se continuar em inglês: no jogo, engrenagem laranja na borda direita da tela > **Display** > **Language** > **Português**.

## Não funcionou?

Dois cliques em **Diagnostico.bat** e mande o que aparecer (ele já copia o texto, é só colar).

## Remover

Dois cliques em **Desinstalar.bat**.
